# Pixlflow

[English version](README.md)

Пиксель-сортер для Windows: окно с живым предпросмотром и командная строка. Изображение режется на
**пути** (строки, круги, спирали, линии потока, нарисованные кистью направления…), на каждом пути
выбираются **участки**, и пиксели участка сортируются по яркости, оттенку и другим величинам — или
обрабатываются эффектом (растяжение, градиент, глитч…). Работает с картинками и с видео.

## Возможности

- **20 видов путей**: строки и столбцы, диагонали под любым углом, лучи, круги и эллипсы, спирали
  (круглая, квадратная, по пропорциям кадра), кривая Гильберта, волны, плитки, змейка, звезда; линии
  потока по шуму, curl-шуму, вихрям, контурам самой картинки или по нарисованным направлениям.
- **Селекторы участков**: весь путь, фиксированная и случайная длина, порог по любой величине
  (в т. ч. «через край», например оттенок 340–20 = красный), края, два условия через И/ИЛИ,
  сглаживание при поиске участков.
- **13 величин для сортировки**: яркость, оттенок, насыщенность, каналы R/G/B, теплота,
  светлота CIE L*, хрома, мин./макс. канал, расстояние до цвета, яркость второго (guide) изображения.
  Порог работает с первыми двенадцатью: guide — это другое изображение, а не цвет пикселя.
- **12 алгоритмов**: стабильная сортировка, расчёска, «сломанная» глитч-сортировка, частичная
  («стекание»), растяжение, сдвиг, градиент, среднее, зеркало, ступени, перемешивание, отладочные цвета.
- **Дополнительно**: ёлочка (Alternate), сортировка одного канала, постеризация, мягкие края участков,
  хроматическая аберрация.
- **Слои** с 10 режимами наложения и непрозрачностью; у каждого слоя своя маска, guide и направления.
- **Кисти**: маска (радиус, жёсткость), прямоугольник и лассо для маски (с мягким краем) и направления; маска из порога, из guide, из файла.
- **Пресеты** — настройки слоя одной строкой текста; именованный список, Random.
- **Анимация** слоя между двумя состояниями → GIF или PNG-кадры.
- **Проекты** (`.pxlf`): все слои, маски и направления вместе с путём к исходнику.
- **Видео**: каждый кадр через весь стек слоёв, звук копируется без перекодирования; живой просмотр.
- **Прозрачность** сохраняется: альфа-канал не сортируется и записывается обратно.

## Установка

Готовая сборка: скачайте zip на странице Releases и распакуйте куда угодно. Это артефакт
`pixlflow-windows` workflow **CI** (запуск вручную или push в `main`) вместе с уведомлениями
о лицензиях (см. «Сторонний код»).

Сборка из исходников (Windows):

1. [Rust](https://rustup.rs) с тулчейном **MSVC** и Visual Studio Build Tools (компонент C++).
   Тулчейн GNU не подходит: он не собирает оконные библиотеки.
2. `cargo build --release` → `target\release\pixlflow.exe`.

Для **видео** нужен FFmpeg, в сборку он не входит: скачайте сборку для Windows по ссылкам с
[ffmpeg.org](https://ffmpeg.org/download.html) (gyan.dev или BtbN) и положите `ffmpeg.exe`,
`ffprobe.exe` и `ffplay.exe` рядом с `pixlflow.exe` или в `PATH`. Без них всё остальное работает.

## Окно

`pixlflow` без аргументов открывает окно. Слева настройки, справа результат, снизу строка статуса.
Изменения сортируются сразу, в фоне; пока тянется слайдер — на уменьшенной копии.

| Клавиши и мышь | Действие |
|---|---|
| Ctrl+O | открыть картинку, видео или проект (или перетащите файл в окно) |
| Ctrl+S | сохранить в папку вывода; имя описывает настройки, существующие файлы не затираются |
| Ctrl+Shift+S | сохранить как… |
| Ctrl+Z / Ctrl+Y, Ctrl+Shift+Z | отменить / повторить (40 шагов, все слои, маски и направления) |
| B | кисть вкл/выкл |
| M | показать маску порога |
| F, двойной клик | вписать изображение в окно |
| колесо / средняя кнопка | масштаб к курсору / панорама |
| кисть: левая / правая кнопка | рисовать / стирать (наоборот с флажком Erase) |
| Rect / Lasso: протянуть | залить маску прямоугольником / нарисованным контуром (правой кнопкой — стереть) |

**Compare** показывает исходник и результат с перетаскиваемым разделителем. **Pick on image** —
задать центр пути или цвет кликом по картинке.

**Слои**: «+ Add» добавляет слой над текущим, «X» или средний клик — удаляет. Каждый слой
применяется к результату слоёв ниже; при изменении пересчитывается только он и слои выше.
Окно показывает весь стек; «Up to this layer» показывает результат выбранного слоя без слоёв над ним
(сохранение по-прежнему берёт все слои).

**Видео** открывается на первом кадре; этот кадр редактируется как картинка. «Frame at» выбирает
другой кадр, «Play sorted» показывает отсортированное видео в окне плеера, «Export video…» пишет
файл со звуком. С флажком «Animate this layer over the clip» текущий слой меняется от Start к End
(раздел Animation) на протяжении ролика.

## Командная строка

```
pixlflow [ОПЦИИ] ВХОД [ВЫХОД]
pixlflow --gui [ОПЦИИ] [ВХОД [ВЫХОД]]
```

`ВХОД`/`ВЫХОД` — файлы или `-` для stdin/stdout (в stdout пишется PNG). Без `ВЫХОДА` результат
сохраняется в `<имя>-sorted.<расш>` рядом со входом. Полный список опций — `pixlflow --help`.

```bash
# круги, порог по оттенку «через край» — сортируются только красные участки
pixlflow photo.jpg out.png --path circles --crit hue --min 340 --max 20

# пресет плюс поправки поверх него
pixlflow --preset "path=flow algo=mirror select=full" --seed 7 photo.png

# конвейер
cat in.png | pixlflow - - --path diagonal --angle 60 > out.png

# маска (того же размера) и guide-изображение
pixlflow photo.png --mask mask.png --guide depth.png --by guide

# видео: весь файл, просмотр, один кадр
pixlflow clip.mp4 --path waves --amplitude 30
pixlflow clip.mp4 --play --algo glitch
pixlflow clip.mp4 --frame-at 12.5 --path spiral

# открыть окно с этими настройками; Save запишет ровно в out.png
pixlflow --gui --path rays photo.png out.png
```

Коды выхода: `0` — успех, `1` — ошибка при работе, `2` — неверные аргументы. `-q` убирает сообщения.

Релизная сборка — оконная программа (без консольного окна). PowerShell и cmd при прямом запуске её
не ждут, поэтому в них используйте `Start-Process -Wait -NoNewWindow pixlflow …`; в Git Bash и
скриптах вывод и коды выхода приходят как обычно.

## Пресеты

Пресет — строка `ключ=значение` через пробел; ключи те же, что опции командной строки:

```
path=circles cx=0.5 cy=0.4 select=threshold crit=hue min=340 max=20 by=brightness algo=sort blend=screen opacity=0.8
```

Неизвестные ключи игнорируются, отсутствующие берут значения по умолчанию. Сохранённые в окне
пресеты лежат в `pixlflow-presets.txt` рядом с программой (одна строка: имя, табуляция, текст).

## Разработка

```bash
cargo test
```

Тесты идут в отладочной сборке (переполнение целых там — ошибка). Тест видео запускается, только
если FFmpeg доступен, иначе пропускается.

| Модуль | Что внутри |
|---|---|
| `src/settings.rs` | настройки слоя и формат пресетов |
| `src/color.rs`, `paths.rs`, `select.rs`, `algo.rs` | величины, пути, селекторы, алгоритмы |
| `src/engine.rs` | конвейер: пути → участки → алгоритм → эффекты → наложение |
| `src/brush.rs`, `anim.rs`, `project.rs`, `video.rs`, `imageio.rs` | кисти, анимация, проекты, видео, файлы |
| `src/gui/` | окно (eframe/egui) |
| `src/main.rs` | командная строка |

## Сторонний код

Уведомления собраны в `THIRD_PARTY_NOTICES.txt`; сборка из CI кладёт его рядом с exe.

- Кривая Гильберта для прямоугольников любого размера — алгоритм «gilbert» Якуба Червени
  (Jakub Červený), лицензия BSD-2-Clause; его уведомление — в этом файле.
- Rust-библиотеки, вкомпилированные в `pixlflow.exe` (egui, image, rayon… и встроенные в egui
  шрифты), идут под MIT, Apache-2.0, OFL и похожими лицензиями. CI собирает их тексты
  [cargo-about](https://github.com/EmbarkStudios/cargo-about) в `CRATE-LICENSES.txt` в артефакте
  (настройки: `about.toml`, `about.hbs`). Локально: `cargo about generate about.hbs -o CRATE-LICENSES.txt`.
- FFmpeg нет ни в исходниках, ни в сборке: Pixlflow лишь запускает установленные пользователем
  программы `ffmpeg` отдельными процессами.
